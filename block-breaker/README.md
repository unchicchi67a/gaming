# ブロックくずし

ブラウザで遊べるブロックくずしです。ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます（`file://` でも動きます）。

## 遊び方

1. タイトル画面で、難易度（Lv1〜100）・速さ・バーの大きさ・ボールの数を選んで「スタート」
2. 指やマウスを左右に動かしてバーを動かします（キーボードの ← → や A / D でも動かせます）
3. 画面をタップ（クリック）するか、スペースキーでボールを打ち出します。タッチのときは、指をはなしたときに打ち出します
4. 色のついたブロックをすべてこわすとクリアです。灰色の鉄のブロックはこわれず、残っていてもクリアになります
5. ボールを下に落とすとボールが 1 つ減り、0 になるとゲームオーバーです

- バーのまん中で打つと真上に、はしで打つほどななめ（最大 60 度）に飛びます
- バーに当たるたびにボールが少しずつ速くなります（そのレベルのはじめの 1.25 倍まで）
- 一時停止：右上のボタン、Esc キー、P キー。ほかのタブに切り替えたときも一時停止します

## 設定

| 設定 | 選べるもの | 内容 |
| --- | --- | --- |
| 難易度 | Lv1〜100 | スライダーか −／＋ ボタン（長押しで連続）で選ぶ。選んだレベルのブロックの並び・数・かたさ・鉄の数・ボールの速さを、その場で表示する |
| 速さ | 遅い / 普通 / 速い | ボールの速さの倍率（0.7 倍 / 1 倍 / 1.35 倍） |
| バーの大きさ | 小さい / 普通 / 大きい / とても大きい | バーの幅の倍率（0.65 倍 / 1 倍 / 1.4 倍 / 1.9 倍） |
| ボールの数 | 1こ / 3こ / 5こ | 落としてもいい回数 |
| 効果音 | ON / OFF | |

設定と記録（クリアした最高レベル・最高スコア）はブラウザに保存されます（`blockbreaker.settings.v1`・`blockbreaker.best.v1`）。

## レベル（難易度）

ステージはレベルの番号から決まった手順で作るので、同じレベルはいつも同じ並びです。レベルが上がると次のように難しくなります。

| | Lv1 | Lv50 | Lv100 |
| --- | --- | --- | --- |
| ブロックの段数 | 4 段 | 8 段 | 12 段 |
| かたさの上限（何回当てるとこわれるか） | 1 | 3 | 5 |
| 鉄のブロック | なし | 少し | 多め（約 14%） |
| ボールの速さ | 1 倍 | 約 1.3 倍 | 1.6 倍 |

- ブロックの段数は 11 レベルごとに 1 段、かたさの上限は 20 レベルごとに 1 増えます。鉄のブロックは Lv15 から出てきます
- ブロックの色が残りの回数を表します（1：緑、2：水色、3：むらさき、4：赤、5：黄色）。2 回以上のブロックには残りの回数の白い点が付き、当てるとひびが入って色が変わります
- 並び方は 10 種類（全面・ピラミッド・市松・ひし形・柱・しま・わく・ばらばら・つばさ・谷）を、レベルの番号で順番に使います
- 鉄のブロックにかこまれて、ボールが届かないブロックができないようにしています（かこんでいる鉄をかたいブロックに置きかえます）
- クリアすると次のレベルに進めます（スコアと残りのボールは引きつぎます）

## 見た目

明るいおもちゃのような見た目です。白い台紙に原色のプラスチック部品を置いたイメージで、ふちどりは紺、影はぼかさない「かたい影」にしています。ボタンは押すと沈みます。タイトルのロゴは 1 文字ずつ色のブロックにのせていて、開いたときに上から落ちてきます（端末で「視差効果を減らす」を設定しているときは動きません）。

## ファイル

```
block-breaker/
├── index.html      画面（タイトルの設定・ゲーム）
├── style.css
├── js/
│   ├── levels.js     レベルの作り方と設定値（画面に触れない。Node.js からも読める）
│   ├── physics.js    ボール・バー・ブロックの動きと当たり判定（画面に触れない。Node.js からも読める）
│   ├── main.js       描画（canvas）・操作・ダイアログ
│   ├── sound.js      効果音（Web Audio API で合成）
│   └── fullscreen.js タッチ端末を横向きにしてタッチすると全画面
└── tests/
    └── breakout.test.js
```

盤面は 600 × 800 の座標で計算し、描くときに画面の大きさに合わせて拡大・縮小します。ボールは 1 回に半径の半分より長く進まないように細かく分けて動かすので、速くてもブロックをすり抜けません。

動作確認用に、`index.html?level=<番号>` でタイトルをとばしてそのレベルから始められます。

## テスト

リポジトリのルートで次を実行します（Node.js 18 以上）。

```sh
node --test block-breaker/tests/breakout.test.js
```

レベルの作り方（すべてのレベルにこわせるブロックがあり、鉄を通らずに届くか・レベルが上がるほど難しくなるか）、設定、当たり判定、残りのボールとゲームオーバー、自動操作でいろいろなレベルを最後までクリアできるか、などを確かめます。
