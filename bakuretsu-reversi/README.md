# 爆裂リバーシ

石を置くと、まわりの8マスが爆風でひっくり返るリバーシです。ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。画面のデザインと CPU のしくみは [`reversi/`](../reversi/) と同じです。

## ルール

1. 石を置けるマスは、通常のリバーシと同じです（相手の石を1つ以上はさめるマスだけ）
2. 置くと、まず通常のリバーシと同じように、はさんだ相手の石を自分の色に裏返します
3. そのあと、置いたマスで爆発が起き、まわり8マスにある石を**色に関係なくすべて**裏返します
   - 自分の石も相手の色になります
   - はさんで裏返したばかりの石も、置いたマスの隣にあれば、もう一度裏返って相手の色に戻ります
   - 空きマスは変わりません。盤の端や隅では、盤の中にあるマスだけが対象です
4. 置ける場所がなければパス、両方とも置けなくなったら終わりで、石の多いほうが勝ちです

隣の石は爆風で裏返るので、はさんだ石のうち自分の色として残るのは、置いたマスから2つ以上離れた石だけです。隅に置いても、あとで隣に置かれると爆風で裏返るため、通常のリバーシのように「取ったら安心」なマスはありません。

## 機能

### タイトル画面
- 対戦モード：CPUと対戦 / 2人で対戦（1台の端末で交互に打つ）
- CPUの強さ：レベル1〜10
- 手番：先手（黒） / 後手（白）
- オプション：置ける場所のヒント表示、効果音の ON/OFF
- 設定はブラウザに保存され、次回も引き継がれます（通常のリバーシとは別に保存します）

### 対局画面
- 上部に石の数（黒 何 対 何 白）と手番を表示
- 一手戻る（回数無制限）。CPU戦では、CPUの手とあなたの手をまとめて戻し、あなたの手番に戻ります
- タイトルに戻る
- 置ける場所のヒント、最後に打たれた手のマーカー、効果音
- 石を置くと、はさんだ石が裏返ったあとに爆発のエフェクト（光・輪・盤のゆれ・爆発音）が出て、まわりの石がいっせいに裏返ります。アニメーションのあいだは次の石を置けません
- 端末で「視差効果を減らす」を設定しているときは、ゆれなどの動きを止めます
- パスの通知、終局時の勝敗表示
- 端末の設定に合わせたダークモード
- 勝ったときは紙ふぶきが舞います

### 1画面表示
ブラウザをスクロールせずに遊べるよう、画面の大きさに合わせて自動でレイアウトを調整します。
- 対局画面：残りのスペースに入るいちばん大きいサイズで盤を表示します。横長の画面では、石の数とボタンを盤の左側に並べます
- タイトル画面：横長の画面では左にロゴ、右にメニューを並べます。それでも収まらない場合は、画面の高さに合わせて全体を縮小します（0.6倍まで。それより小さい画面ではスクロールします）

### デザイン
子ども向けの「おもちゃのボードゲーム」がテーマです。押すとへこむ立体ボタン、トマト色の盤のふち、ぶ厚いコインのような石、空色の水玉の背景で構成しています。文字は子どもが読めるよう、ひらがなを中心にしています。フォントは Google Fonts の Mochiy Pop One（ロゴ・数字）と M PLUS Rounded 1c（本文）を使い、読み込めない環境では端末の丸ゴシック体で表示します。

## CPUのレベル

タイトル画面では「−」「＋」ボタンか、だんだん高くなる10本のバーをタップしてレベルを選びます。バーの色が難しさ（緑＝やさしい・青＝ふつう・オレンジ＝むずかしい・赤＝さいきょう）を表します。最初はレベル3（入門）が選ばれています。

| レベル | 名前 | 難しさ | 目安 |
| --- | --- | --- | --- |
| 1 | ルール練習 | やさしい | でたらめに打つ。ルールを覚えたい人向け |
| 2 | はじめて | やさしい | 石がたくさん増える手を選びがち。ときどき適当に打つ |
| 3 | 入門 | やさしい | 角などの大事なマスを意識するが、先読みはしない。判断にムラがある |
| 4 | 初級 | ふつう | 2手先まで読む。ミスは多め |
| 5 | 初級＋ | ふつう | 2手先まで読み、相手の打てる場所を減らす作戦も使う |
| 6 | 中級 | ふつう | 3手先まで読み、ミスはほとんどしない |
| 7 | 中級＋ | むずかしい | 4手先まで読む。残り8マスから最後まで読み切る |
| 8 | 上級 | むずかしい | 5手先まで読む。残り10マスから読み切る |
| 9 | 上級＋ | さいきょう | 6手先まで読む。残り12マスから読み切る |
| 10 | 最強 | さいきょう | 最大8手先まで読む。残り14マスから読み切る |

思考時間は1手あたり最大およそ1.5秒です（読み切れない場合はそれまでの結果で打ちます）。

先読みは爆風も含めて正しく計算しています。ただし盤面の評価（角を重く見るなど）は通常のリバーシ用の表をそのまま使っているため、爆裂ルールに合わせた調整の余地があります。

## スマートフォンで横向きにしたとき
- スマートフォン・タブレットを横向きにして画面をタッチすると、全画面になります。縦向きに戻すと全画面をやめます
  - ブラウザの制限で、全画面はタッチしたときにしか始められないため、横向きにしただけでは切り替わりません
  - 横向きのまま自分で全画面をやめた（戻る操作など）ときは、縦向きにしてもう一度横向きにするまで、全画面にしません
  - パソコンでは何もしません
- iPhone の Safari は全画面に対応していません。共有ボタンから「ホーム画面に追加」して開くと、ブラウザのバーなしで表示されます

## ファイル構成

```
bakuretsu-reversi/
├── index.html      画面の構造
├── style.css       見た目（ダークモード対応）
├── js/engine.js    ルール（合法手の判定・着手と爆風・石数）
├── js/ai.js        CPUの思考ルーチン
├── js/sound.js     効果音（Web Audio API で合成。爆発音を含む）
├── js/fullscreen.js スマートフォンで横向きにしたときの全画面
├── js/main.js      画面制御
└── tests/          ルール（爆風）とCPUのテスト
```

## テスト

Node.js（v18 以上）で実行します。

```sh
node --test bakuretsu-reversi/tests/bakuretsu.test.js
```
