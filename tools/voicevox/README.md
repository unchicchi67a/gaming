# VOICEVOX の音声づくり

「3びきのこぶた」と「おみせやさんごっこ」のせりふを、[VOICEVOX](https://voicevox.hiroshiba.jp/) で音声ファイル（MP3）にするスクリプトです。

声はすべて **VOICEVOX:冥鳴ひまり**（ノーマル）です。

VOICEVOX は自分の環境で動かすソフトなので、遊んでいる人のブラウザからは呼べません。そのため、せりふをあらかじめ音声ファイルにしてリポジトリに入れています。ゲーム側（各ゲームの `js/voice.js`）は、音声ファイルがあればそれを再生し、なければブラウザの音声合成（Web Speech API）で読み上げます。

## クレジットと利用規約

- VOICEVOX の利用規約：https://voicevox.hiroshiba.jp/term/
- 冥鳴ひまりの利用規約：https://www.meimeihimari.com/terms-of-use

冥鳴ひまりの音声は、「VOICEVOX:冥鳴ひまり」とクレジットを書けば、商用・非商用で使えます。各ゲームの画面（「3びきのこぶた」はタイトル画面、「おみせやさんごっこ」は「おうちの方へ」の設定画面）と README にクレジットを書いています。

## 音声ファイルのつくり方

必要なもの：Docker、Node.js 18 以上、ffmpeg（MP3 への変換に使う）

```sh
# 1. VOICEVOX Engine を起動する（CPU 版。初回は 2GB ほどのダウンロードがあります）
docker run --rm -d --name voicevox -p 50021:50021 voicevox/voicevox_engine:cpu-latest

# 2. 音声ファイルをつくる（リポジトリのルートで実行）
node tools/voicevox/generate.js              # すべてのゲーム
node tools/voicevox/generate.js omiseyasan   # ゲームを指定する

# 3. 終わったらエンジンを止める
docker stop voicevox
```

- 出力：`<ゲーム>/voice/<ハッシュ>.mp3` と、せりふと音声ファイルの対応表 `<ゲーム>/js/voice-lines.js`
- ファイル名は「読み＋声の設定」のハッシュなので、変わっていないせりふはつくり直しません。使われなくなった音声ファイルは消します
- エンジンの場所は環境変数 `VOICEVOX_URL` で変えられます（既定は `http://127.0.0.1:50021`）
- CPU 版だと、150 個ほどのせりふで 5〜6 分かかります

せりふを足したり変えたりしたら、音声ファイルをつくり直して、`voice/` と `js/voice-lines.js` もいっしょにコミットしてください。各ゲームのテストが、音声ファイルのないせりふを見つけると失敗します。

## せりふの集め方（`lines.js`）

各ゲームの `js/main.js` にある文字列リテラルのうち、**ひらがな・カタカナを含み、漢字と HTML を含まないもの**をせりふとみなします（子ども向けのせりふはひらがな・カタカナだけで書いているため）。画面に出す見出しなど、読み上げない文字列もいくつか含まれますが、音声ファイルが増えるだけで害はありません。

テンプレート文字列の `${…}` は、`games.js` の `placeholders` で値の候補を決め、すべての組み合わせに展開します（例：`${itemName(order.item)} ください！` → 品物 18 個ぶん）。候補が決まっていない `${…}` を含むテンプレート文字列は対象外です。

ゲーム側では、分かち書きのスペースを取り除いた文（`speakable()`）をキーにして音声ファイルを探します。

## 読みまちがいを直す

```sh
node tools/voicevox/generate.js --kana   # 音声はつくらず、VOICEVOX の読み（カナとアクセント）を表示する
```

読みがおかしいせりふは、`generate.js` の表で直します（画面の文字はそのまま）。

- `READING`：読ませる文の一部を差しかえる（例：「こぶた」→「コブタ」）
- `KANA`：差しかえで直らないせりふは、読みとアクセントを AquesTalk 風の記法で直接書く（`'` がアクセント、`/` がアクセント句の区切り、`、` が息つぎ、`_` が無声化）。`--kana` の表示を手本にする

## 声の設定（`games.js`）

| 項目 | 値 | 意味 |
| --- | --- | --- |
| speaker | 14 | 冥鳴ひまり（ノーマル）のスタイル ID |
| speedScale | 0.92 | 小さい子が聞き取りやすいよう少しゆっくり |
| intonationScale | 1.15 | 抑揚を少し大きめに |
| prePhonemeLength / postPhonemeLength | 0.1 / 0.15 | 前後の無音（秒） |

設定を変えるとファイル名のハッシュが変わるので、すべての音声がつくり直されます。
