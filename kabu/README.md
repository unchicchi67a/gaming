# おおきなかぶ とばし

昔話「おおきなかぶ」をもとにしたゲームです。おじいさん、おばあさん、まご、いぬ、ねこ、ねずみを順番に呼んでかぶを引っぱり、ぬけたかぶを届け先までぴったり飛ばします。

ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。

## 遊び方

1. タイトルでステージを選びます（「🎲 ランダム」で、10 個のステージからランダムに 1 つ）
2. まずはおじいさんが 1 人で「うんとこしょ！」。それでもかぶはぬけません
3. 「〇〇を よぶ」ボタンを**押しているあいだ**、次の種類の仲間が集まってきます。人間は 1 人ずつ、動物は長く押すほどどんどん速く集まります（パソコンではスペースキー）
4. 「うんとこしょ！」（パソコンでは Enter キー）で引っぱると、次の種類に進みます。もとの種類にはもどれません
5. ねずみまでそろえて引っぱると根っこが切れて、かぶが飛んでいきます
6. 着いたところと届け先とのずれが、OK の範囲（画面左上）に入ればクリアです

### 力の決まり方

- 力は「**種類ごとの力の合計**」を、すべての種類で**かけ算**したものです
- 1 人（1 匹）ごとに 5 段階の強さがあります（人間ならガリガリ・ほそめ・ふつう・がっしり・ムキムキ、いぬなら子いぬ・小型犬・ふつう・大型犬・ムキムキ犬など）。だれが来るかはランダムで、見た目で強さの順番はわかりますが、何倍なのかは画面に出しません
- 何人来たかも数字では出しません。群れの絵の大きさで見ます
- 力がかぶの重さより弱いと、ねずみまでそろえてもぬけません。かぶの重さは毎回少しちがい、見た目の大きさに出ます

### かぶの動き方（ヒント）

ねずみより前の「うんとこしょ」では、かぶの動き方で「届け先まで、あとどれくらい力が要るか」がわかります。あと少しになるほど、かぶが土から出てきます。

| 動き方 | 意味 |
| --- | --- |
| しーん…… / ぴくりともしない | まだまだぜんぜん足りない |
| ピクッ…… / ぐらっ | まだかなり足りない |
| ぐらぐら / ぐらぐらぐら！ | だいぶ近づいてきた |
| メリッ / メリメリ……！ / メリメリメリッ！！ | あと少し |
| ミシミシッ！ 根っこが切れそう | ほぼちょうど |
| ブチブチッ！？ 根っこが悲鳴をあげている | もう強すぎる |

ステージが進むほど、動き方は少しあいまいになり、強さのばらつき（ガリガリやムキムキの出やすさ）も大きくなります。

### コツ

- 数が多い種類ほど、1 人（1 匹）ふえたときの変化は小さくなります（かけ算なので、1000 匹が 1001 匹になっても力はほとんど変わらない）。人間でおおまかに、動物で細かく合わせるのが基本です
- 最後のねずみで細かく合わせられるように、ねずみの分を少し残しておくとクリアしやすくなります

## ステージ

| ステージ | 届け先（どれか 1 つがランダム） | OK の範囲 |
| --- | --- | --- |
| 1 | 台所のおなべ（5 m）、井戸（7 m）、にわとり小屋（9 m） | ±50% |
| 2 | 小川（35 m）、となりの畑（50 m） | ±45% |
| 3 | 村の市場（300 m）、丘の上のお寺（450 m） | ±40% |
| 4 | 峠の茶屋（2.5 km）、となり村（4 km） | ±40% |
| 5 | 港町（30 km）、お城（45 km） | ±35% |
| 6 | 雪山のてっぺん（300 km）、みやこ（500 km） | ±35% |
| 7 | 海のむこうの島（3,000 km）、砂漠の国（5,000 km） | ±30% |
| 8 | 南極（1.5 万 km）、地球の裏側（2 万 km） | ±30% |
| 9 | 月（38.4 万 km） | ±25% |
| 10 | 火星（7,800 万 km） | ±25% |

OK の範囲は届け先までの距離に対する割合なので、遠い届け先ほど、メートルで見た範囲は広くなります。

クリアしたステージには ★ と、いちばん小さかったずれが表示されます（ブラウザに保存）。すべてのステージは最初から選べます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の部品（タイトル・プレイ中の表示・結果） |
| `style.css` | 見た目（手づくりの絵本のデザイン） |
| `js/game.js` | ルール（描画なし。ブラウザと Node.js の両方から読み込める） |
| `js/main.js` | canvas の描画と操作 |
| `js/fullscreen.js` | タッチ端末を横向きにして画面をタッチすると全画面にする |
| `tests/kabu.test.js` | ルールとバランスのテスト |

難しさは `js/game.js` の `STAGES`（OK の範囲 `tol`、ヒントのあいまいさ `noise`、強さのばらつき `spread`、かぶの重さ `weight`）と `SPECIES`（集まる速さと最大の数）で調整します。

URL に `?debug` をつけると、ブラウザの開発者ツールから `window.__game()` でゲームの状態を読めます。

## テスト

リポジトリのルートで実行します。

```sh
node --test kabu/tests/kabu.test.js
```

ルールのほか、ボットを使ったバランスの確認（ヒントをよく読むボットが、でたらめに押すボットよりずっとクリアできること、どのステージも必勝ではないこと、先のステージほど難しいこと、火星にも届くこと、ねずみで細かく合わせるのが大事なこと）をしています。
