# 「こたつ」制作メモ

最初の版を作ったときの会話（2026-11-13）の要点です。遊び方や機能は [README.md](README.md)、作業のルールはルートの [CLAUDE.md](../CLAUDE.md) にあります。

## 経緯

- 「インスタで見たような変なゲーム」（オムライスにケチャップで絵を描く、せっかちな客をタクシーで運ぶ など）を作りたい、という相談から始まった
- 出したアイデア 10 個の中から「猫をこたつから出さないゲーム」に決まった
  - 候補だったほかのアイデア：たこ焼き職人（タコが逃げる）、かき氷シロップ配分、ラーメン湯切り選手権、行き先がコロコロ変わるエレベーター係、「いい感じで」としか言わない美容院の客、ハトに豆を平等にあげる係、満員電車テトリス、ハンコをまっすぐ押すだけ、シャンプー泡立て耐久
- フォルダ名はユーザーの希望で `kotatsu`（最初は `kotatsu-cat` で作ったが変更した）

## ユーザーが決めたこと

- 対象は大人
- まずは Claude が考えたかたちで作り、そのあとで細かい動きや絵を一緒に変えていく

## 最初の版で Claude が決めたこと（変更してよい）

- 部屋を真上から見た四畳半。こたつのふとんの 4 辺から、猫が 1 匹ずつ出てくる
- 操作は 3 つ：猫をタップで押し戻す（押しすぎると怒って出ていく）、おやつ（1 晩 3 個）、温度（弱・中・強）
- 温度は「寒いと出る・ちょうどいいと出ない・熱すぎると飛び出す」。「強」と「中」を切りかえるのがコツになるようにした
- 1 晩は 21:00 → 7:00 を約 2 分（`DURATION = 120` 秒）。4 匹ぜんぶ出たら負け、出ていった猫は 8〜12 秒で戻ってくる
- 物音のイベント 3 種類（ピンポーン・冷蔵庫・鳥）
- 猫 4 匹：もち（白・のんびり）、こむぎ（茶トラ・ふつう）、のり（黒・すぐ出る）、ボス（三毛・短気）
- 結果に称号（ただの暖房器具 / 猫の下僕 / こたつ番長 / こたつ奉行 / こたつの神、負けたときは「猫に見捨てられし者」）と電気代を出す
- 絵は SVG、効果音は Web Audio API で合成（画像・音声ファイルなし）。`imagegen` での絵の生成はまだ使っていない

## バランス調整の記録

- 最初の数値では、テストの自動操作（0.3 秒に 1 回反応）が毎回猫を 1 匹も逃さず満点近くになり、簡単すぎた
- 次のように難しくした
  - 猫が出てくる速さ：0.09 → 0.2（夜明け）だったのを 0.12 → 0.3 に
  - ちょうどいい温度のときの速さの倍率：0.35 → 0.45（ちょうどいい温度でも少しは動く）
  - 押し戻す量：0.4 → 0.35
  - イライラのおさまる速さ：0.06 → 0.035（同じ猫を何度も押しにくくした）
- 調整後：上手な自動操作（0.45 秒に 1 回反応）でも 1 晩に 1〜3 回は猫に出ていかれ、スコアは 6700〜7000 くらい。温度を管理しない自動操作は、30 回中 5 回ほど負ける。放置すると 15〜20 秒ほどで負ける
- 称号の基準も、これに合わせて 2500 / 4000 / 5500 / 6600 にした

## 見た目の確認で直したこと

- 手前の猫が出きる直前に、顔が画面の下からはみ出していた → こたつ（ふとん 540 → 440）と猫（0.82 倍、ボスは 0.92 倍）を小さくした
- 物音のお知らせが、奥の猫の吹き出しと重なっていた → お知らせをこたつの天板の上（画面のまん中）に出すようにした

## 次にやること（候補）

- 1 晩の長さ
