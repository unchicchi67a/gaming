# こたつ

冬の夜、こたつから出ていこうとする猫を、朝まで出さないようにする大人向けのゲームです。ビルドや外部ライブラリなしで動きます。

## 遊び方

`index.html` をブラウザで開き、「こたつに入る」を押すと始まります。

- こたつの中には猫が 4 匹います。猫はふとんの 4 辺（手前・右・奥・左）から、それぞれじわじわ出てきます
- 21:00 から朝 7:00 まで（約 2 分）耐えるとクリアです。4 匹ぜんぶが外に出たら負けです
- 出ていった猫は、しばらくすると戻ってきます

### 操作

| 操作 | 内容 |
| --- | --- |
| 猫をタップ（クリック） | こたつの奥に押し戻す。押すたびに猫のイライラがたまり、たまりきると「シャーッ!!」と怒って出ていく。イライラは時間がたつと少しずつおさまる |
| おやつ → 猫をタップ | 猫を奥にもどし、機嫌をなおす。猫はしばらく（10 秒）出てこない。1 晩に 3 個まで |
| 温度（弱・中・強） | 寒いと猫は出ていく。ちょうどいい温度（温度計の緑のところ）だとほとんど動かない。熱すぎる（赤のところ）と、のぼせて飛び出してくる。「強」で上がり、「中」でふつうにもどり、「弱」で下がる |

キーボードでは、1・2・3 で温度（弱・中・強）、T でおやつ、Esc か P で一時停止できます。

### 猫

| 名前 | 毛の色 | 性格 |
| --- | --- | --- |
| もち | 白 | のんびり。めったに怒らない |
| こむぎ | 茶トラ | ふつうの猫 |
| のり | 黒 | 好奇心のかたまり。すぐ出る |
| ボス | 三毛 | 短気。さわりすぎ注意 |

### できごと

ときどき物音がして、猫がそわそわします。

- ピンポーン（宅配便）：全員が少し出てくる
- 冷蔵庫の開く音：しばらく全員の出てくる速さが上がる
- 窓の外に鳥：1 匹だけ、しばらく速く出てくる

おやつで満足している猫は、物音を気にしません。

### スコア

こたつの中にいる猫の数 × 時間で「ぬくぬく」がたまります。ちょうどいい温度のときは 1.5 倍です。クリアすると称号と、押し戻した回数・電気代などの記録が出ます。自己ベストはブラウザに保存されます。

## 機能

- 絵はすべて SVG で描いています（画像ファイルなし）。部屋を真上から見た 1000 × 1000 の座標で描き、画面の大きさに合わせて拡大・縮小します
- 効果音は Web Audio API で合成しています（音声ファイルなし）。タイトルで切りかえられます
- 縦長の画面では上に情報・下に操作、横長の画面では左に情報・右に操作を置きます
- スマートフォン・タブレットを横向きにして画面をタッチすると全画面になります（`js/fullscreen.js`）
- 別のタブに切りかえると一時停止します
- `?play` をつけて開くと、タイトルをとばしてすぐ始まります（動作確認用）

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `js/game.js` | 進行（猫の動き・温度・イベント・スコア）。画面に触れない純粋なロジックで、ブラウザと Node.js の両方から読み込める |

| `NOTES.md` | 制作メモ（経緯・決めたこと・バランス調整の記録・次にやること） |

## テスト

リポジトリのルートで次のコマンドを実行します。

```sh
node --test kotatsu/tests/kotatsu.test.js
```

ゲームの進み方のほか、バランス（何もしないと朝までもたないこと、人が遊ぶのに近い自動操作ならたいてい朝まで耐えられること）も確かめています。猫の速さや温度などの数値を変えたら、このテストが通るかを確かめてください。
