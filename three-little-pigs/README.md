# 3びきのこぶた

3歳くらいの子ども向けの、ブラウザで遊べる絵本ゲームです。昔話「三匹の子ぶた」のお話を、タッチや息の「ふーっ」で進めます。ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。

スマートフォン・タブレット・パソコンのどれでも遊べます。画面の向きや大きさに合わせて、舞台が画面いっぱいに広がります（スマートフォンは横向きにすると大きく表示されます）。

## お話の流れ

| 場面 | 子どもがすること |
| --- | --- |
| わらの家をつくる | 画面をタッチするたびに、わらが積み上がる（5回で完成） |
| オオカミがわらの家をふきとばす | マイクに「ふーっ」と息をふきかける（またはタッチ）。1回でふきとぶ |
| 木の家をつくる | タッチで板を組み立てる（6回で完成） |
| オオカミが木の家をふきとばす | 1回目はぐらぐら、2回目でふきとぶ |
| レンガの家をつくる | タッチでレンガを積む（8回で完成） |
| オオカミがレンガの家をふく | 3回ふいてもびくともせず、オオカミは屋根にのぼる |
| だんろのおなべにお湯をためる | タッチでおなべに水を入れる（4回でお湯がわく） |
| エンディング | えんとつから落ちたオオカミが「あちち」と飛び出し、こぶたたちに謝って仲直りする |

最後は、オオカミが反省して、こぶたたちと一緒になかよく暮らすお話になっています。

## 機能

### 3歳でも遊べるように
- 字が読めなくても進められるよう、語りとせりふはブラウザの音声合成で読み上げます。日本語の音声がない端末では、文字だけで表示します
- 画面のどこをタッチしても、その場面の操作になります。小さなボタンを狙う必要はありません
- 失敗はありません。どこを押しても、お話は必ず先へ進みます
- 操作できる場面では、画面上部に「タッチ！」「ふーっ！」の目印と、あと何回で進むかの丸印を出します。しばらく操作がないと、タッチする場所に手のマークが出ます
- 語りやアニメーションの再生中のタッチは、きらきらが出るだけで物語は進みません
- 遊んでいる途中で左上の家のボタンを押すと「おわりに する？」と確認します。うっかり押しても戻れます

### 息で「ふーっ」
- タイトル画面の「いきで ふーっ」を ON にすると、オオカミの場面でマイクに息をふきかけてオオカミに吹かせられます。遊んでいる途中でも、右上のマイクのボタンで ON / OFF できます
- マイクを使っているときは、「ふーっ」の目印の横に音の大きさのメーターが出て、息の強さに合わせてオオカミのほっぺがふくらみます
- マイクが使えない・許可されない場合も、タッチで同じように遊べます
- 判定のしくみ：まわりの雑音の大きさを自動で学習し、それより十分大きい音が 0.15 秒以上続いたら「ふーっ」とみなします。手をたたく音のような短い音では反応しません。一度判定したら、いったん静かになるまで次は判定しません
- 息の音を消してしまわないよう、ブラウザのノイズ抑制・エコー除去・自動音量調整は切ってマイクを使います

**マイクは HTTPS か `localhost` で開いたときに使えます**（ブラウザのセキュリティ上の制限です）。パソコンの Chrome などでは `file://` で開いても使えることがありますが、スマートフォン・タブレットで息の操作を使うには、HTTPS で公開したページ（GitHub Pages など）か、GitHub Codespaces のポート転送の URL で開いてください。

### 読み上げの声
- 声の質は端末に入っている音声で決まります。自然に聞こえるニューラル音声を自動で優先して選びます
  - Edge：Microsoft Nanami などの「Online (Natural)」の声（いちばん自然です）
  - Chrome：Google 日本語
  - iPhone / iPad / Mac：Kyoko や O-ren の「拡張」「プレミアム」の声（「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」からダウンロードできます）
- タイトル画面の「こえ」で、端末にある日本語の声から選べます。選ぶと試しに読み上げます
- 声の高さを大きく変えると機械っぽく聞こえるため、話す人ごとの違い（オオカミは少し低く、こぶたは少し高く）はひかえめにしています
- 画面の文字はひらがなの分かち書きですが、読み上げるときはスペースを取り除き、言葉が途切れないようにしています

### 音と設定
- 効果音は音声ファイルを使わず、Web Audio API で合成しています
- タイトル画面で「よみあげ」「こうかおん」をそれぞれ ON / OFF できます。遊んでいる途中は右上のスピーカーのボタンで、すべての音をまとめて消せます
- 設定はブラウザに保存され、次回も引き継がれます

### デザイン
「朝の光が差す絵本」がテーマです。絵はすべて SVG でコードから描いていて、画像ファイルはありません。
- キャラクターは、体の輪郭を曲線で描き、色えんぴつのような茶系のやわらかい線で縁取っています。光は太陽のある右上から当たるようにそろえ、影は左下側に入れています
- こぶたは見分けやすいよう、1ぴきめは耳に花、2ひきめはスカーフ、3びきめはちょうネクタイをつけています。オオカミはつぎはぎの半ズボンとサスペンダー姿です
- わらの家はひもでしばったわらの束と、ふさふさの屋根。木の家は切り口に年輪のある丸太小屋。レンガの家は色ムラのあるレンガ、アーチの入口、花のプランターつきの窓です
- 地面に落ちるやわらかい影で、地面に立っている感じを出しています
- 遠くの山は青くかすませて奥行きを出し、画面全体にうっすらと紙のような粒子感を重ねています
- 家の中では、だんろの火の明かりが部屋を照らし、お湯がわくと明かりが強くなります
- 文字・ボタンは、景色が透けて見えるすりガラス風のパネルにしています
- フォントは Google Fonts のしっぽり明朝 B1（タイトル）と Zen 丸ゴシック（本文）を使い、読み込めない環境では端末の明朝体・丸ゴシック体で表示します

## ファイル構成

```
three-little-pigs/
├── index.html      画面の構造
├── style.css       見た目・キャラクターの表情の切り替え・アニメーション
├── js/story.js     物語の進行ルール（場面の順番、必要なタッチ回数など）
├── js/breath.js    「ふーっ」の判定（マイクの音量から判定する）
├── js/art.js       絵（こぶた・オオカミ・家・背景などの SVG と、共通のグラデーション）
├── js/sound.js     効果音（Web Audio API で合成）
├── js/voice.js     語りとせりふの読み上げ（Web Speech API。自然な声を優先して選ぶ）
├── js/mic.js       マイク入力（音量を求めて判定へ渡す）
├── js/main.js      画面制御（演出の再生と操作の受け付け）
└── tests/          物語の進行と「ふーっ」判定のテスト
```

`js/story.js` と `js/breath.js` は画面に触れない純粋なロジックで、ブラウザと Node.js の両方から読み込めます。

## 開発用：途中の場面から始める

URL に `?scene=<場面名>` を付けてタイトルの ▶ を押すと、その場面から始まります。

場面名：`straw-build` / `straw-blow` / `wood-build` / `wood-blow` / `brick-build` / `brick-blow` / `pot-fill` / `ending`

例：`index.html?scene=brick-blow`

## テスト

Node.js（v18 以上）で実行します。

```sh
node --test three-little-pigs/tests/pigs.test.js
```
