# 3びきのこぶた

3歳くらいの子ども向けの、ブラウザで遊べる絵本ゲームです。昔話「三匹の子ぶた」のお話を、タッチや息の「ふーっ」で進めます。ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。

スマートフォン・タブレット・パソコンのどれでも遊べます。画面の向きや大きさに合わせて、舞台が画面いっぱいに広がります（スマートフォンは横向きにすると大きく表示されます）。

## お話の流れ

| 場面 | 子どもがすること |
| --- | --- |
| わらの家をつくる | 画面をタッチするたびに、わらが積み上がる（5回で完成） |
| オオカミがわらの家をふきとばす | マイクに「ふーっ」と息をふきかける（またはタッチ）。1回でふきとぶ |
| 木の家をつくる | タッチで板を組み立てる（6回で完成） |
| オオカミが木の家をふきとばす | 1回目はぐらぐら、2回目でふきとぶ |
| レンガの家をつくる | タッチでレンガを積む（8回で完成） |
| オオカミがレンガの家をふく | 3回ふいてもびくともせず、オオカミは屋根にのぼる |
| だんろのおなべにお湯をためる | タッチでおなべに水を入れる（4回でお湯がわく） |
| エンディング | えんとつから落ちたオオカミが「あちち」と飛び出し、こぶたたちに謝って仲直りする |

最後は、オオカミが反省して、こぶたたちと一緒になかよく暮らすお話になっています。

## 機能

### 3歳でも遊べるように
- 遊ぶ子はお話をだいたい知っている前提なので、お話を説明する語り（地の文）はありません。お話はキャラクターのせりふと動きで進みます
- 字が読めなくても進められるよう、せりふと遊び方の案内を読み上げます（声は VOICEVOX の冥鳴ひまり）
- 画面に出す文字はできるだけ減らしています。せりふは、話しているキャラクターの頭の上に吹き出しで出します
- 遊び方の案内（「おおかみを タッチして、ふーっ！」など）はふだん文字では出さず、読み上げだけにしています。タイトル画面の「もじ」を ON にすると、画面の下に文章も出ます（日本語の読み上げ音声がない端末向け）
- 画面のどこをタッチしても、その場面の操作になります。小さなボタンを狙う必要はありません
- 失敗はありません。どこを押しても、お話は必ず先へ進みます
- 操作できる場面では、画面上部に、あと何回で進むかの丸印を出します（文字は出しません）
- さわってほしいもの（わらの山・オオカミ・水さし）は、やわらかく光って、ぴょこんと跳ねて知らせます。操作がないまましばらくたつと、もう一度光ります
- せりふやアニメーションの再生中のタッチは、きらきらが出るだけで物語は進みません
- 遊んでいる途中で左上の家のボタンを押すと「おわりに する？」と確認します。うっかり押しても戻れます

### 息で「ふーっ」
- タイトル画面の「いきで ふーっ」を ON にすると、オオカミの場面でマイクに息をふきかけてオオカミに吹かせられます。遊んでいる途中でも、右上のマイクのボタンで ON / OFF できます
- マイクを使っているときは、画面上部にマイクのマークと音の大きさのメーターが出て、息の強さに合わせてオオカミのほっぺがふくらみます
- マイクが使えない・許可されない場合も、タッチで同じように遊べます
- 判定のしくみ：まわりの雑音の大きさを自動で学習し、それより十分大きい音（雑音の 3 倍以上、かつ音量 0.03 以上）が 0.12 秒以上続いたら「ふーっ」とみなします。声で「ふーっ」と言っても反応します。手をたたく音のような短い音では反応しません。一度判定したら、いったん静かになるまで次は判定しません
  - マイクを開いた直後の 0.25 秒は判定せず、まわりの雑音を急いで学習します（テレビがついている部屋などで、開いたとたんに反応しないように）
  - うるさい部屋でも、判定に必要な音量が上がりすぎないよう、学習する雑音の大きさには上限があります
- 息の音を消してしまわないよう、ブラウザのノイズ抑制・エコー除去・自動音量調整は切ってマイクを使います
- マイクを開くのは、オオカミの場面で「ふーっ」を待っているあいだだけです。せりふや効果音が鳴るときは、マイクを閉じます
  - スマートフォンでは、マイクを開いているあいだ音の出力が通話用に切りかわり、声がガサガサに聞こえるためです
  - マイクの使用許可は、▶ を押したときに一度だけ聞きます

**マイクは HTTPS か `localhost` で開いたときに使えます**（ブラウザのセキュリティ上の制限です）。パソコンの Chrome などでは `file://` で開いても使えることがありますが、スマートフォン・タブレットで息の操作を使うには、HTTPS で公開したページ（GitHub Pages など）か、GitHub Codespaces のポート転送の URL で開いてください。

### 読み上げの声
- せりふと案内は、[VOICEVOX](https://voicevox.hiroshiba.jp/) の「冥鳴ひまり」であらかじめつくった音声ファイル（`voice/*.mp3`）を再生します。端末に日本語の読み上げ音声がなくても、同じ声で聞こえます
  - 案内・こぶた・オオカミはすべて同じ声です
  - 音声ファイルのつくり方は [`tools/voicevox/README.md`](../tools/voicevox/README.md) を見てください
- 音声ファイルがないせりふや、再生できなかったときは、ブラウザの音声合成（Web Speech API）で読み上げます
- タイトル画面の「こえ」で、冥鳴ひまりのかわりに端末にある日本語の声を選ぶこともできます。選ぶと試しに読み上げます
- 端末の声を使うときは、声の質は端末に入っている音声で決まります。自然に聞こえるニューラル音声を自動で優先して選びます
  - Edge：Microsoft Nanami などの「Online (Natural)」の声（いちばん自然です）
  - Chrome：Google 日本語
  - iPhone / iPad / Mac：Kyoko や O-ren の「拡張」「プレミアム」の声（「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」からダウンロードできます）
- 端末の声では、声の高さを大きく変えると機械っぽく聞こえるため、話す人ごとの違い（オオカミは少し低く、こぶたは少し高く）はひかえめにしています
- 画面の文字はひらがなの分かち書きですが、読み上げるときはスペースを取り除き、言葉が途切れないようにしています
- 音声のクレジット（VOICEVOX:冥鳴ひまり）は、タイトル画面のいちばん下に出しています

### 音と設定
- 効果音は音声ファイルを使わず、Web Audio API で合成しています
- タイトル画面で「よみあげ」「もじ」「こうかおん」をそれぞれ ON / OFF できます。遊んでいる途中は右上のスピーカーのボタンで、すべての音をまとめて消せます
- 設定はブラウザに保存され、次回も引き継がれます

### スマートフォンで横向きにしたとき
- スマートフォン・タブレットを横向きにして画面をタッチすると、全画面になります。縦向きに戻すと全画面をやめます
  - ブラウザの制限で、全画面はタッチしたときにしか始められないため、横向きにしただけでは切り替わりません
  - 横向きのまま自分で全画面をやめた（戻る操作など）ときは、縦向きにしてもう一度横向きにするまで、全画面にしません
  - パソコンでは何もしません
- iPhone の Safari は全画面に対応していません。共有ボタンから「ホーム画面に追加」して開くと、ブラウザのバーなしで表示されます

### デザイン
水彩と色えんぴつで描いた絵本のような見た目です。
- こぶた・オオカミ・家・材料・水さし・おなべ・だんろ・背景は、画像生成 AI（Stable Diffusion XL）で作った画像です（`img/`）。作り方は下の「絵について」を見てください
- こぶた 3 びきは同じ 1 枚の絵から作り、シャツの色だけを変えています（1ぴきめは黄色、2ひきめはオレンジ、3びきめは青）。顔や体の形がそろうので、きょうだいらしく見えます
- 表情は、顔のまわりだけを描き直した画像を重ねて切り替えます。こぶたは「ふつう・にこにこ・こわがる」、オオカミは「ふつう・ほっぺをふくらませる・ふーっ・へとへと・あちち・ごめんね・にっこり」です
- マイクで息を吹いているあいだは、息の強さに合わせて、ほっぺをふくらませたオオカミの絵がじわっと重なります
- 家の絵は横に切り分けてあり、タッチするたびに下から 1 段ずつ積み上がります。ふきとぶときは、段ごとにばらばらに飛んでいきます
- 汗・なみだ・湯気・ばんそうこう・炎・風・ハート・きらきらは、絵の上に重ねる SVG です
- 画面の形によって見える範囲が変わるので、背景の絵のふちはぼかし、そのまわりは空や地面の色でぬっています
- 家の中では、だんろの火の明かりが部屋を照らし、お湯がわくと明かりが強くなります
- せりふの吹き出しは、縁の色で話している人がわかります（1ぴきめはからし色、2ひきめはセージ、3びきめはブルーグレー、オオカミはグレー）
- ボタンや案内の文章は、景色が透けて見えるすりガラス風のパネルにしています
- フォントは Google Fonts のしっぽり明朝 B1（タイトル）と Zen 丸ゴシック（本文）を使い、読み込めない環境では端末の明朝体・丸ゴシック体で表示します

### 絵について
画像は [`tools/imagegen/`](../tools/imagegen/)（Modal の GPU で Stable Diffusion XL を動かすスクリプト）で作りました。モデルのライセンスは CreativeML Open RAIL++-M です。
1. 元になる絵（こぶた・オオカミ・家・背景など）を、絵本風の水彩という共通の指示で何枚か作り、よいものを選ぶ
2. 表情ちがいは、元の絵の顔のまわりだけを描き直す（インペイント）。描き直した範囲の外は元の絵のままなので、体や服はずれません
3. 背景を取り除いて透過にし（rembg）、表情ちがいの絵がぴったり重なるよう、同じ範囲で切り抜いて大きさをそろえる
4. こぶたのシャツの色は、オレンジの部分の色相だけを変えて黄色と青にする

こぶたは、オオカミと同じ画風（色えんぴつと水彩、細い線、2 本足の立ち姿で服を着ている）になるよう、オオカミの絵に合わせた指示で作り直しました。元の絵で手に持っていた不要な金具は、インペイントで消しています。

絵を差し替えるときは、`js/art.js` の先頭にある画像の大きさや足元の位置（`SPRITES`・`HOUSE_IMG` など）も合わせて直してください。

## ファイル構成

```
three-little-pigs/
├── index.html      画面の構造
├── style.css       見た目・キャラクターの表情の切り替え・アニメーション
├── js/story.js     物語の進行ルール（場面の順番、必要なタッチ回数など）
├── js/breath.js    「ふーっ」の判定（マイクの音量から判定する）
├── js/art.js       絵の置き方（画像の位置と大きさ、表情の重ね方、家の切り分け）と、効果（汗・炎・風など）の SVG
├── img/            絵の画像（WebP。こぶた・オオカミの表情ごとの絵、家、材料、背景など）
├── js/sound.js     効果音（Web Audio API で合成）
├── js/fullscreen.js スマートフォンで横向きにしたときの全画面
├── js/voice.js     せりふと案内の読み上げ（VOICEVOX の音声ファイルを再生。ないときは Web Speech API）
├── js/voice-lines.js せりふと音声ファイルの対応表（tools/voicevox/generate.js が自動でつくる）
├── voice/          VOICEVOX（冥鳴ひまり）でつくったせりふの音声（MP3）
├── js/mic.js       マイク入力（音量を求めて判定へ渡す）
├── js/main.js      画面制御（演出の再生、吹き出しの位置合わせ、操作の受け付け）
└── tests/          物語の進行・「ふーっ」判定・音声ファイルのそろい具合のテスト
```

`js/story.js` と `js/breath.js` は画面に触れない純粋なロジックで、ブラウザと Node.js の両方から読み込めます。

## 開発用：途中の場面から始める

URL に `?scene=<場面名>` を付けてタイトルの ▶ を押すと、その場面から始まります。

場面名：`straw-build` / `straw-blow` / `wood-build` / `wood-blow` / `brick-build` / `brick-blow` / `pot-fill` / `ending`

例：`index.html?scene=brick-blow`

`?micdebug` を付けると、画面の左下にマイクの音量（level）・直近 2 秒の最大値（peak）・学習した雑音の大きさ（floor）・判定に必要な音量（trigger）を出します。実機で「ふーっ」の感度を調べるときに使います（例：`index.html?scene=straw-blow&micdebug`）。

## テスト

Node.js（v18 以上）で実行します。

```sh
node --test three-little-pigs/tests/pigs.test.js
```
