# おつかい できるかな？

3歳くらいの子ども向けの、ブラウザで遊べるおつかいゲームです。お母さんのメモを見て、町のお店で品物を買ってきます。お金の計算はなく、メモに描かれた品物を、描かれた数だけタッチするだけで遊べます。ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。

スマートフォン・タブレット・パソコンのどれでも遊べます。縦向き・横向きのどちらでも、画面に合わせて並びが変わります。

## 遊び方

1. タイトルの「はじめる」をタッチします
2. おうちで、お母さん（うさぎ）が「おつかい おねがいね！」とメモを見せてくれます。メモには、行くお店・品物の絵・数が描いてあります。「いってきます！」で出発します
3. 町の地図には、おうちと 3 けんのお店（やおやさん・くだものやさん・パンやさん）がならんでいます。お店をタッチすると中に入ります
4. お店の棚から、メモの品物をタッチすると、品物がかごへ飛んでいきます。メモの数だけ買うと「できた！」のスタンプが出て、町にもどります
5. メモのものをぜんぶ買ったら、おうちが光って「かえろう！」と出ます。おうちをタッチすると、お母さんがよろこんでおしまいです

## レベル

タイトル画面の「おうちの方へ」で選びます。最初はレベル1です。

| レベル | 行くお店 | 品物 |
| --- | --- | --- |
| 1 | 1けん | 1しゅるいを 1こ（棚に 3つ並ぶ） |
| 2 | 1けん | 1しゅるいを 2〜3こ（棚に 4つ並ぶ） |
| 3 | 2けん | 1けんで 1しゅるいを 1〜2こ（棚に 4つ並ぶ） |
| 4 | 3けん | 1けんで 1〜2しゅるいを 1〜2こずつ。全部で 4しゅるいまで（棚に 4つ並ぶ） |

## 機能

### 3歳でも遊べるように
- 字が読めなくても分かるよう、メモは「お店の絵・品物の絵・大きな数字・○の数」で描いています。買うたびに ○ が緑にうまり、そろうとお花のスタンプが押されます
- メモは、町でもお店の中でも、右上の「メモ」ボタンでいつでも見られます
- 失敗はありません
  - メモにない品物をタッチすると、品物がぷるぷるして買わず、メモボタンがはねて、このお店で買う品物が光ります。このお店で買うものがないときは「もどる」ボタンが光ります
  - もうメモの数だけ買った品物をタッチすると、買わずに「品物と ○○●」を出して、足りていることを見せます
  - まだ買いおわっていないのにおうちをタッチすると、おうちがぷるぷるしてメモを開きます
- 何もしないで 8 秒たつと、町ではメモのいちばん上の買いおわっていないお店を、お店の中ではメモの品物（なければ「もどる」ボタン）を光らせます
- 遊んでいる途中で左上の ✕ を押すと「おわりに する？」と確認します
- 子どもがさわる画面には設定を置かず、タイトル画面右上の「おうちの方へ」から開くようにしています
- 声の読み上げはまだありません（効果音と BGM だけ鳴ります）

### 設定（タイトル画面の「おうちの方へ」）
| 設定 | 内容 |
| --- | --- |
| レベル（1〜4） | 上の表のとおり |
| 効果音 | ベル・品物を買う音・スタンプなど |
| 音楽 | BGM（効果音が OFF のときは流れません） |

設定はブラウザ（`localStorage`）に保存され、次に開いたときも引き継がれます。遊んでいる途中は、右上のボタンで音をまとめて消せます。

### ふるまいのルール
- メモの品物と行くお店は、毎回ランダムに選びます。メモはお店ごとにまとめて並べます
- どのお店の棚にも、メモの品物と、メモにない品物がまざって並びます（メモに入っていないお店にも入れます）
- 町のお店の窓には、そのお店の棚の品物が見えます

### 見た目
「おみせやさんごっこ」と同じ「木のおもちゃ」の見た目です。ふちどりはこげ茶、影はぼかさない「かたい影」にしています。

- 品物・お店の外観・町の絵は「おみせやさんごっこ」の絵（`../omiseyasan/js/art.js`）をそのまま使っています
- お母さん・おうち・かごの絵は `js/art.js` で描いています。お母さんは、おみせやさんごっこのうさぎの絵にエプロンと髪かざりを足したものです
- 絵はすべて SVG で描いていて、画像ファイルは使っていません

### スマートフォンで横向きにしたとき
- スマートフォン・タブレットを横向きにして画面をタッチすると、全画面になります。縦向きに戻すと全画面をやめます
  - ブラウザの制限で、全画面はタッチしたときにしか始められないため、横向きにしただけでは切り替わりません
  - 横向きのまま自分で全画面をやめた（戻る操作など）ときは、縦向きにしてもう一度横向きにするまで、全画面にしません
  - パソコンでは何もしません
- iPhone の Safari は全画面に対応していません。共有ボタンから「ホーム画面に追加」して開くと、ブラウザのバーなしで表示されます

### 動作確認用
- `index.html?level=3` のように `?level=<1〜4>` を付けると、タイトルをとばして、そのレベルで始まります（設定には保存しません）

## ファイル構成

```
otsukai/
├── index.html        画面の骨組み
├── style.css         見た目（お店ごとの色は [data-shop] で切り替え）
├── js/
│   ├── errand.js     おつかいの進行（メモと棚を決める・買った品物の判定）
│   ├── art.js        このゲームだけの絵（お母さん・おうち・かご）
│   ├── sound.js      効果音と BGM（おみせやさんごっこと同じもの）
│   ├── fullscreen.js スマートフォンで横向きにしたときの全画面
│   └── main.js       画面の進行
└── tests/            進行のテスト
```

品物とお店のデータ（`../omiseyasan/js/items.js`）と絵（`../omiseyasan/js/art.js`）は、おみせやさんごっこのフォルダから読み込みます。おみせやさんごっこに品物を足すと、このゲームにも出てきます。

## テスト

Node.js（v18 以上）で実行します。

```sh
node --test otsukai/tests/otsukai.test.js
```
