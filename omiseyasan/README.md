# おみせやさんごっこ

3歳くらいの子ども向けの、ブラウザで遊べるお店屋さんごっこです。お客さんが「にんじん ください！」と言ったら、お店の棚から同じ品物をタッチしてわたします。ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。

スマートフォン・タブレット・パソコンのどれでも遊べます。縦向き・横向きのどちらでも、画面に合わせて棚の並びが変わります。

## 遊び方

1. タイトル画面に並んだ 3 けんのお店から、1 つをタッチします
   - やおやさん（にんじん・だいこん・トマト・キャベツ・なす・とうもろこし）
   - くだものやさん（りんご・バナナ・みかん・ぶどう・いちご・すいか）
   - パンやさん（しょくぱん・メロンパン・クロワッサン・ドーナツ・フランスパン・ホットドッグ）
2. シャッターが上がって開店。お客さん（うさぎ・くま・ねこ・いぬ・パンダ）がやってきて、ほしい品物を言います
3. カウンターの品物をタッチすると、品物がお客さんの手もとへ飛んでいきます
4. わたすたびに、スタンプカードにお花のスタンプが押されます。5 人にわたしたら閉店です

## 見た目と演出

「木のおもちゃのお店」をテーマに、お店の中からお客さんを見る構図にしています。

- 奥に空と町、手前に木のカウンター。ひさしとかんばんの色はお店ごとに変わります
- 品物はお店ごとの入れものに入っています（やおやさん＝木箱、くだものやさん＝かご、パンやさん＝トレー）
- 開店・閉店のときは、お店のシャッターが上がったり下りたりします
- お客さんはまばたきをしたり、品物を受け取るとぴょんっと跳ねて、手に持ったまま帰っていきます
- 正解の音は、お客さんが進むごとに少しずつ高くなります
- オルゴール風の BGM が流れます（設定で OFF にできます）
- 絵はすべて SVG で描いていて、画像ファイルは使っていません

## 機能

### 3歳でも遊べるように
- 字が読めなくても遊べるよう、せりふはブラウザの音声合成で読み上げます。お客さんごとに声の高さを少し変えています
- 注文の吹き出しには、品物の名前と一緒に絵も出します（設定で OFF にすると名前だけになります）
- 失敗はありません。ちがう品物をわたすと、お客さんが「それは トマト だね。にんじん は どれかな？」とやさしく言い直し、ほしい品物が光ってぴょこぴょこ動きます
- 何もしないで 8 秒たつと、お客さんがもう一度注文を言います。2 回目からは、ほしい品物も光らせます
- お客さんや吹き出しをタッチすると、注文をもう一度聞けます
- お客さんが話している途中に品物をさわっても、ぴょこっと動くだけで先へは進みません
- 遊んでいる途中で左上の家のボタンを押すと「おわりに する？」と確認します
- 子どもがさわる画面には設定を置かず、タイトル画面右上の「おうちの方へ」から開くようにしています

### 設定（タイトル画面の「おうちの方へ」）
| 設定 | 内容 |
| --- | --- |
| 品物の数（3 / 4 / 6） | 棚に並べる品物の数。はじめは 3〜4 がおすすめ |
| 注文に絵を出す | 注文の吹き出しに品物の絵を出す |
| 読み上げ | せりふを読み上げる。日本語の声が複数ある端末では「声」で選べる |
| 効果音 | ベル・スタンプ・シャッターなどの効果音 |
| 音楽 | BGM（効果音が OFF のときは流れません） |

設定はブラウザ（`localStorage`）に保存され、次に開いたときも引き継がれます。遊んでいる途中は、右上のボタンで音をまとめて消せます。

### ふるまいのルール
- 棚の品物は、お店の 6 つの中から毎回ランダムに選びます
- 注文は棚の品物からまんべんなく選び、同じ品物が 2 回続かないようにしています
- 同じお客さんも 2 回続けては来ません
- 音（BGM・効果音・読み上げ）は、ブラウザの制限のため、最初に画面をさわったあとから鳴ります

### 動作確認用
- `index.html?shop=yaoya` のように `?shop=<お店の id>`（`yaoya` / `kudamono` / `panya`）を付けると、タイトルをとばしてそのお店から始まります

## ファイル構成

```
omiseyasan/
├── index.html        画面の骨組み
├── style.css         見た目（お店ごとの色と入れものは [data-shop] で切り替え）
├── js/
│   ├── items.js      お店・品物・お客さんのデータ
│   ├── shop.js       遊びの進行（棚と注文を決める・わたした品物の判定）
│   ├── art.js        品物・お客さん・町・お店の外観などの絵（SVG 文字列）
│   ├── sound.js      効果音と BGM（Web Audio API で合成）
│   ├── voice.js      読み上げ（Web Speech API）
│   └── main.js       画面の制御
└── tests/
    └── shop.test.js  進行とデータのテスト
```

`items.js`・`shop.js`・`art.js` は画面に触れない純粋なロジック／データで、ブラウザと Node.js の両方から読み込めます。`file://` で開いても動くよう、ES Modules は使わず通常の `<script>` で読み込んでいます。

## テスト

リポジトリのルートで次のコマンドを実行します（Node.js 18 以上）。

```sh
node --test omiseyasan/tests/shop.test.js
```
