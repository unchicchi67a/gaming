# 名刺交換 低さバトル

名刺は相手より低い位置から差し出すのがマナー。取引先の部長も負けじと下げてくるので、お辞儀からひざをつき、土下座して、床をぶち抜き、地層を掘り進み、地球の中心まで名刺を下げ合う、読み合いのゲームです。

ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。

## 遊び方

- 「さげる」ボタン（または画面のどこか）を押しているあいだ、名刺が下がります。パソコンではスペースキーか ↓ キーでも操作できます
- 2 人とも止まると「**間（ま）**」ができ、間が満ちたら名刺交換になります。**そのとき名刺が低いほうの勝ち**です
- 地球の中心に先に着いたら、その場で勝ちです（めったに届きません）

### 間（ま）と名刺交換

| いま低いほう | 間が満ちるまで | 画面の表示 |
| --- | --- | --- |
| あなた | 2 秒。そのあいだに部長が下げ返してこなければ勝ち | 青いゲージ「このまま間が満ちれば勝ち」 |
| 部長 | 毎回ちがう（1.3〜2.6 秒）。部長が名刺を差し出したら負け | 赤いゲージ「部長がいつ名刺を出すか…」。差し出す少し前に「では、改めまして……」と言い、ゲージが点滅する |
| 同じ高さ | 2 秒。満ちたら引き分け（お見合い） | 灰色のゲージ「お見合い中…」 |

だれかが押しているあいだ、間は止まります（0 にはもどりません）。0 にもどるのは、どちらが低いかが入れかわったときだけです。

### 腰

- 押しているあいだ「あなたの腰」ゲージが減り、止まっていると少しずつ回復します
- **押しつづけるほど腰の減りが増えます**。少しずつ抜くのは楽ですが、一気に深く突き放すのはキツい
- 床より上（お辞儀と床掘り）は、地下より腰への負担が軽いです
- 新しい地層に**一番乗り**すると、腰が少し回復します
- 腰が 0 になると、ぎっくり腰で負けです

### 部長

- **部長の腰ゲージは見えません**。「部長のようす」（😌 余裕 / 😅 汗 / 😩 ハァハァ）と、下げおわったあとのひとことで読みます。ただし部長は、疲れていても余裕の顔をする（やせがまん）ことも、余裕があるのに疲れた顔をする（疲れたふり）こともあります
- 部長の腰の強さは毎回ちがいます（タフな部長も、ひ弱な部長もいます）
- 部長は抜かれると、あなたが止まるのを待ってから、下げ返すか諦めるかを決めます。下げ返す腰が足りなさそうなら諦めます
- 部長も**あなたの汗を見ています**。あなたの腰が減っていると、あなたが返せない深さまで一気に突き放してきます
- 結果の画面で、部長の腰がどれだけ残っていたか（種明かし）がわかります

### 読み合いのコツ

- 部長が弱っていると読めたら、**部長が返せない深さまで一気に突き放す**とトドメになります。読みが外れると、自分がバテて逆に突き放されます
- 部長が余裕そうなら、少しずつ抜いて腰を温存しましょう
- 抜かれたあと、ギリギリまで待つほど腰は回復しますが、部長がいつ名刺を差し出すかはわかりません

### 床より上

名刺を下げるにつれて「会釈 → 敬礼 → 最敬礼 → ひざをつく → 土下座 → 床にはりつく」と段階が進み、そのたびに部長とやりとりします。部長は最初から会釈していて、最初に動くのはあなたです。床より上では、地下よりゆっくり下がります。

床まで下げたら、押しつづけて床を掘ります（左上に何 % 掘ったかが出ます）。掘りきると床をぶち抜いて地下に進めます。部長も同じように床を掘ります。地下は深いほど速く下がるので、読み合いが続くほど、どんどん深く潜っていきます。

### じゃまもの

| じゃまもの | 場所 | 内容 |
| --- | --- | --- |
| 🚃 電車 | 地下鉄 | トンネルの信号が赤く点滅し、ライトが近づいてきたら電車が来る合図。トンネルにいるとひかれて気絶し、少し上に押し戻される |
| ♨️ 間欠泉 | 温泉の源泉 | お湯がぶくぶくしたら噴き出す合図。お湯の層にいると吹き飛ばされて気絶し、大きく押し戻される |

部長も当たります。部長は気づいて手前で待つこともありますが、気づかずに突っこむこともあるので、抜くチャンスです。だれかが気絶しているあいだは、間は進みません。

### 勝ち負け

| 結果 | 内容 |
| --- | --- |
| 勝ち：名刺交換成立 | 自分が低いまま間が満ちた |
| 勝ち：地球の中心 | 先に地球の中心に着いた |
| 勝ち：部長がぎっくり腰 | 部長の腰が先に限界をむかえた |
| 引き分け：お見合い | 同じ高さのまま間が満ちた |
| 負け：部長に先を越された | 部長が低いまま間が満ち、部長が名刺を差し出した |
| 負け：ぎっくり腰 | 自分の腰が 0 になった |
| 負け：部長が先に地球の中心へ | 部長に先に着かれた |
| 負け：「お先にどうぞ」と言ってしまった | 「お先にどうぞ」ボタンを押した |

## 機能

- 名刺を下げると、まずお辞儀をし、ひざをつき、床を掘ってぶち抜き、頭から潜っていきます
- 地層：オフィスの床下 → 地下駐車場 → 地下鉄 → 地下水脈 → 化石の地層 → 温泉の源泉 → 油田 → 岩盤 → マントル → 外核 → 内核 → 地球の中心
  - 新しい地層に着くと、部長がその地層についてひとこと言います
  - 深さの表示は、地下に行くほど速く増えます
- 左の縦のバーで、自分（青）と部長（赤）が地球のどのあたりにいるかがわかります
- 勝つと、名刺交換した場所の深さで称号が決まります（常識ある社会人 / できる社会人 / できる営業 / 伝説の営業 / 名刺交換の神）
- タッチ端末を横向きにして画面をタッチすると全画面になります（`js/fullscreen.js`）
- `?debug` をつけて開くと、外からゲームの状態（`window.__game()`）を読めます（自動操作での動作確認用）

## ファイル

```
meishi/
├── index.html        画面（タイトル・プレイ中の表示・結果）
├── style.css
├── js/
│   ├── game.js       ルールと部長の考え方（描画なし。ブラウザと Node.js の両方から読み込める）
│   ├── main.js       canvas の描画と操作
│   └── fullscreen.js 横向きで全画面にする
└── tests/
    └── meishi.test.js
```

難しさは `js/game.js` の `TUNING` で調整できます。おもな値：

- 腰：`drain`（減り方）、`strain`（押しつづけたときの増え方）、`recover`（回復）、`surfaceDrain`（床より上の軽さ）、`layerBonus`（一番乗りの回復）
- 速さ：`playerVmax` / `oppV`、`surfaceSlow`（床より上）、`deepen`（地下での加速）、`floorTime`（床を掘る時間）
- 間：`maPlayer`、`oppPatience`、`reachLead`
- 部長：`oppStart`（最初の会釈）、`oppStamina`（腰の強さの幅）、`oppReact`、`oppMargin` / `oppBigMargin`（下げ返す量）、`oppKill`（トドメを狙う確率）、`oppReserve` / `oppPride`（諦めぐあい）、`oppBluffCalm` / `oppBluffTired`（顔のうそ）

じゃまものの場所・間隔・押し戻す量は `HAZARDS` で変えられます。

## テスト

リポジトリのルートで次のコマンドを実行します（Node.js 18 以上）。

```sh
node --test meishi/tests/meishi.test.js
```

深さと地層の計算、腰の減り方と見こみ、間と名刺交換の判定、部長の考え方（諦める・トドメを狙う・顔のうそ）、床・地層・じゃまもの、勝ち負けのほか、決まった遊び方をするボットを何回も戦わせて、読み合いになっているか（顔色を読んでトドメを狙うボットが、毎回大きく突き放すボットや毎回少しだけ抜くボットより勝てること、ただし必勝ではないこと、読み合いが続くと地下まで潜ること）を確かめています。
