# 名刺交換 低さバトル

名刺は相手より低い位置から差し出すのがマナー。取引先の部長も負けじと下げてくるので、お辞儀からひざをつき、土下座して、床をぶち抜き、地層を掘り進み、地球の中心まで名刺を下げ合うゲームです。

ビルドや外部ライブラリは不要で、`index.html` をブラウザで開くだけで動きます。

## 遊び方

- 「さげる」ボタン（または画面のどこか）を押しているあいだ、名刺が下がります。パソコンではスペースキーか ↓ キーでも操作できます
- 先に**地球の中心**に着いたら勝ちです

### 床より上

名刺を下げるにつれて「会釈 → 敬礼 → 最敬礼 → ひざをつく → 土下座 → 床にはりつく」と段階が進み、そのたびに部長とやりとりします。床より上では、地下よりゆっくり下がります。

床まで下げたら、押しつづけて床を掘ります（左上に何 % 掘ったかが出ます）。掘りきると床をぶち抜いて地下に進めます。部長も同じように床を掘ります。

### じゃまもの

| じゃまもの | 場所 | 内容 |
| --- | --- | --- |
| 🚃 電車 | 地下鉄 | トンネルの信号が赤く点滅し、ライトが近づいてきたら電車が来る合図。トンネルにいるとひかれて気絶し、少し上に押し戻される |
| ♨️ 間欠泉 | 温泉の源泉 | お湯がぶくぶくしたら噴き出す合図。お湯の層にいると吹き飛ばされて気絶し、大きく押し戻される |

部長も当たります。部長は気づいて手前で待つこともありますが、気づかずに突っこむこともあるので、抜くチャンスです。

### 負けになること

| できごと | 内容 |
| --- | --- |
| 失礼な人だと思われた | 部長より名刺が高いあいだは「失礼度」がたまり、満タンになると負け。部長より低いあいだは少しずつ減る |
| ぎっくり腰 | 押しているあいだは「あなたの腰」ゲージが減り、0 になると負け。離すと回復する |
| 部長が先に地球の中心へ | 部長に先に着かれると、もう下げられないので負け |
| 「お先にどうぞ」と言ってしまった | 「お先にどうぞ」ボタンを押すと、その場で負け |

### コツ

部長にも腰ゲージがあります。部長は追い抜かれると少し遅れて下げ返してきますが、あなたより少し遅く、腰が限界になると、ある程度回復するまで休みます（「ハァ…ハァ…」）。部長の腰ゲージが少ないときに一気に抜くのが有利です。

電車や間欠泉の予告が出たら、手前で止まって通りすぎるのを待ちましょう。

## 機能

- 名刺を下げると、まずお辞儀をし、ひざをつき、床を掘ってぶち抜き、頭から潜っていきます
- 地層：オフィスの床下 → 地下駐車場 → 地下鉄 → 地下水脈 → 化石の地層 → 温泉の源泉 → 油田 → 岩盤 → マントル → 外核 → 内核 → 地球の中心
  - 新しい地層に着くと、部長がその地層についてひとこと言います
  - 深さの表示は、地下に行くほど速く増えます（1 秒あたりに進むのは同じでも、マントルでは何百 km も進む）
- 左の縦のバーで、自分（青）と部長（赤）が地球のどのあたりにいるかがわかります
- 勝つと、かかった時間で称号が決まります（名刺交換の神 / 伝説の営業 / できる社会人 / 期待の新人）
- タッチ端末を横向きにして画面をタッチすると全画面になります（`js/fullscreen.js`）

## ファイル

```
meishi/
├── index.html        画面（タイトル・プレイ中の表示・結果）
├── style.css
├── js/
│   ├── game.js       ルールと部長の動き（描画なし。ブラウザと Node.js の両方から読み込める）
│   ├── main.js       canvas の描画と操作
│   └── fullscreen.js 横向きで全画面にする
└── tests/
    └── meishi.test.js
```

難しさは `js/game.js` の `TUNING`（自分と部長の速さ、床より上での速さ、床を掘る時間、腰ゲージの減り方・回復のしかた、失礼度のたまり方、部長の反応の速さ、部長がじゃまものに気づく確率）で調整できます。じゃまものの場所・間隔・押し戻す量は `HAZARDS` で変えられます。

## テスト

リポジトリのルートで次のコマンドを実行します（Node.js 18 以上）。

```sh
node --test meishi/tests/meishi.test.js
```

深さと地層の計算、深さの表示、勝ち負けの判定、床より上の段階、床を掘る時間、じゃまものの当たり方のほか、決まった押し方をするボットを何回も戦わせて、難しさが極端になっていないか（何もしない・押しっぱなしでは必ず負け、腰ゲージを見ながら押せばほぼ勝てる、雑に押すとときどき負ける）を確かめています。
